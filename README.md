# 对话生成器 — Dialogue Generator

TWEWY（《美妙世界》）风格对话生成器：**脚本驱动**，既能**导出单帧/整段 PNG 图片**，又能**实时播放可互动的对话序列**（打字机效果、分支选择、跳转）。复刻自 [twewy-message-generator](https://twewygenerator.heckingsne.cc/)（作者 Errant）的渲染布局，实现细节见 [ANALYSIS.md](ANALYSIS.md)。

## 运行

```bash
# 方式一：本地服务器（推荐，浏览器限制最少）
node serve.js            # 然后打开 http://localhost:8080/

# 方式二：直接双击 index.html（file:// 下也可用，导出功能在部分浏览器受限）
```

## 快速上手

1. 打开页面自动载入 `samples/demo.txt` 示例。
2. 左侧为实时预览：**点击画面 / 空格 / Enter** 下一句，**←** 上一句，**R** 重开。
3. 右侧有三个标签页：
   - **脚本**：直接编辑 DSL 文本，输入即解析；出错会列出错误行。
   - **编辑器**：所见即所得编辑——在行列表中选择/新建/删除/上下移动每一行，用表单调整
     说话人（方向）、表情立绘、对话框形式、翻转、内容等。**草稿模式**：表单里的修改先暂存，
     不会打断预览播放，点「✔ 确定」（或 Ctrl+Enter）才真正应用；「取消」丢弃修改；
     切换到其他行会自动应用未确定的修改。
   - **资源**：新建角色（上传多张表情立绘 + 多句语音；每张立绘可单独调整**缩放/上下左右位移**，
     调整在每次播放中保持一致并随角色包导出）、新建地点（上传多张背景画面，
     如早晨/中午/夜晚）、上传背景音乐与音效；均可打包分享、导入他人包。
4. 点「保存当前帧 PNG」或「导出全部帧 PNG」（倍率可调，默认 2x = 1334×1000）。

## 立绘素材

**本项目不附带任何角色立绘**（你不需要 TWEWY 的角色）。两种用法：

- 直接放文件：`assets/sprites/` 下按 `{角色id}{表情编号}.png` 命名（`alice1.png`、`alice2.png`…），
  脚本里 `!actor … | sprites/{id}{expr}.png`。
- 用**资源页**管理：新建角色 → 上传表情立绘 → 脚本里用 `chara://角色id/表情编号` 引用；
  打包成 `.dgchar.json` 分享，别人「导入角色包」即用。

背景同理：内置素材在 `assets/bg/`；资源页可建"地点"（一个地点多张画面），
脚本里 `@bg loc://地点id/画面id`，可打包成 `.dgloc.json` 分享。
**音频**：资源页上传背景音乐（`bgm://音乐id`，`@bgm` 循环播放）、音效（`sfx://音效id`，
`@sfx` 播放一次），可打包成 `.dgbgm.json` / `.dgsfx.json`；每个角色可上传多句**语音**
（`{voice=语音编号}` 播放，随角色包一起导出）。**立绘调整**：角色卡片里每张立绘可点「调」
打开调整面板，缩放 50%~200%、上下左右 ±150px，实时预览并即时生效（每次播放一致，随角色包导出）。
资源数据保存在浏览器 localStorage（音频较占空间，超限会提示；打包文件不受限，建议音频用短片段）。

## 脚本语法（DSL）参考

`//` 或 `#` 开头为注释。空行忽略。

### 场景指令

| 语法 | 说明 |
| --- | --- |
| `@bg <路径>` | 换背景。`assets/bg/` 下的文件名可直接写名字（如 `Event_BG_sh001_01.jpg`），也可写任意相对路径 |
| `@title <文本>` | 场景标题（显示在状态栏） |
| `@label <名字>` | 标记一个跳转点 |
| `@end` | 序列结束 |
| `@shownames on\|off` | 气泡上是否显示说话人名字（默认 on） |
| `@mirrorleft on\|off` | 左侧立绘是否水平镜像朝向中间（默认 on） |
| `@wrap on\|off` | 超长文本自动换行（默认 on；`\n` 始终换行） |
| `@fontsize <px>` | 气泡文字大小（默认 20） |
| `@speed <ms>` | 打字速度：每字符毫秒数，`0` 为瞬间显示（默认 28） |
| `@autodelay <ms>` | 打完字后自动进入下一句的延迟；`0` 表示等玩家点击（默认 0） |
| `@slotgap <px>` | 同一侧前后槽位的立绘重叠间距（默认 40） |
| `@exportscale <n>` | 导出 PNG 倍率（默认 2） |
| `@trans on\|off` | 句与句之间的对话框转场动画（默认 on） |
| `@transdur <ms>` | 转场动画时长（默认 380） |
| `@transdist <px>` | 转场垂直位移距离（默认 110） |
| `@bgm <路径\|off>` | 背景音乐：`bgm://音乐id` 或文件路径，循环播放；`off` 停止 |
| `@sfx <路径>` | 音效：`sfx://音效id` 或文件路径，播放一次 |

### 角色（立绘）管理

```
!actor <id> = <显示名> | <left|right> | <front|back|slot0..3> | <立绘模板> [| flip|noflip] [| expr=<n>]
!actor <id> <显示名> <left|right> <front> <立绘模板> <flip|noflip> <expr=3>   # 空格分隔写法
```

- 立绘模板支持占位符 `{id}`（角色 id）和 `{expr}`（表情编号，默认 1），如 `sprites/{id}{expr}.png`。
- **水平翻转**：末尾加 `flip` 强制水平翻转立绘，`noflip` 禁止翻转；
  不写则按全局 `@mirrorleft`（默认左侧角色镜像朝内）。编辑器里也有对应的下拉选项。
- **默认表情**：`expr=<n>` 指定角色默认使用第 n 号立绘；不写默认 1。
  编辑器「立绘选择」可直接从该角色的立绘缩略图点选（资源角色枚举上传的立绘，
  文件模板自动探测 `{expr}` 对应图片），选完写为 `expr=N`。每句对话仍可用
  `alice(2)` / `{expr=2}` 临时换表情。
- 资源角色模板：`chara://角色id/{expr}`（立绘来自资源页，打包/导入可分享）。
- 背景可用资源地点：`@bg loc://地点id/画面id`。
- 同一侧可叠多人：`front`（槽位 0，最前）→ `back`（槽位 1）→ `slot2`/`slot3` 依次向后。
- 中途指令：`!actor on|off <id>`（上下场）、`!sprite <id> <表情编号>`（换立绘/表情）。

### 对话行

```
说话人{属性}: 内容
说话人1+说话人2{属性}: 内容        # 多人共用一个气泡
*{属性} 内容                       # 旁白：无名字、居中、不翻转
++ 甲{属性}: 内容A || 乙{属性}: 内容B   # 一次显示两个气泡（后层 || 前层）
```

行内属性 `{k=v,k2=v2}`（可放在说话人后或行首）：

| 属性 | 说明 |
| --- | --- |
| `box=` | 对话框形式：`default` / `thought`（思考）/ `wiggly`（抖动）/ `loud`（吼） |
| `expr=<n>` | 本句使用的立绘表情编号（等价于 `id(n)` 写法，如 `alice(3):`） |
| `flip=auto\|0\|1` | 气泡翻转（决定投影方向）；`auto` 默认朝说话人一侧翻转 |
| `speed=<ms>` | 本句打字速度覆盖 |
| `name=<文本>` | 名字标签覆盖 |
| `side=left\|right` | 气泡朝向覆盖 |
| `voice=<n>` | 播放说话人（首个说话人）的第 n 号语音（资源页上传） |

### 分支与跳转

```
? 选项文案 -> 标签名        # 连续多个 ? 组成一个选择菜单，点选后跳到标签
-> 标签名                   # 无条件跳转（跳到名为 end 的标签 = 直接结束）
@label 标签名
```

## 播放/导出行为说明

- **交互播放**：打字中点击 = 立即显示全文；再点 = 下一句。选择菜单用按钮点选。
- **播放模式**：点「▶ 播放模式」后自动走完整段脚本——每句打完自动进下一句
  （间隔约 1.4s），选择分支自动取第一项；勾选「循环」播完自动重头；再点一次停止。
- **录制成视频**：点「● 录制视频」开始实时录制预览画面+声音（WebM，含 BGM/音效/语音），
  播放完脚本后点「■ 停止录制」自动下载。建议配合播放模式使用。
  录制需要浏览器支持 canvas.captureStream 与 MediaRecorder（Chrome/Edge/Firefox 均支持）。
- **音频**：`@bgm` 行到达时循环播放 BGM（`@bgm off` 停止）；`@sfx` 播放一次音效；
  对话行带 `{voice=n}` 时播放该角色第 n 号语音。**同一时刻只允许一路 BGM**（重复触发/
  快速跳转也不会叠加）；批量导出不会播放任何音频。预览下方有 BGM / 音效 / 语音三路音量滑块。
  浏览器自动播放策略：页面**第一次点击/按键**时自动解锁音频，之后播放模式/编辑器里的
  BGM、语音都会出声；状态栏会显示当前 BGM 名称，加载失败会在控制台输出 `[audio]` 日志。
- **转场动画**：每进入新一句，上一句的对话框整体**上移淡出**（快起慢动 ease-out），
  新对话框从画面**中下方升起**到居中的"当前对话框位置"（同样快起慢动）。打字效果与
  升起同时进行；转场中点按可立即完成转场。`@trans off` 可关闭。
- **单帧导出**：导出当前画面（选择菜单不会画进 PNG，转场中间帧也不参与）。
- **批量导出**：按顺序回放脚本，每句对话导出一张 PNG（跳过选择菜单，遇到分支只走默认路径，
  有死循环会报错）。下载文件名 `dialogue_001.png` …（浏览器会限速下载，逐张间隔触发）。

## 目录结构

```
index.html            应用入口（file:// 可直接打开）
css/style.css         UI 样式
js/parser.js          脚本解析器（文档条目模型 + op 时间线，可单独在 Node 中用）
js/renderer.js        canvas 渲染器（复刻原站 667×500 布局数学）
js/player.js          序列播放状态机（打字机 / 选择 / 跳转 / 转场 / 导出）
js/resources.js       资源库（角色立绘+语音 / 地点背景 / BGM / 音效，chara:// loc:// bgm:// sfx:// 引用，打包/导入）
js/audio.js           Web Audio 引擎（BGM 循环、音效、语音、三路音量）
js/editor.js          所见即所得行编辑器（选择/新建/删除/移动 + 上下文表单）
js/app.js             UI 胶水（标签页、预览、导出、资源页）
assets/bubbles/       4 种对话框素材
assets/bg/            20 张背景素材
assets/font/          FOT-NewCezanne Pro M 字体
assets/sprites/       占位立绘（换成你的）
samples/demo.txt      示例脚本
tools/                gen_placeholders.js（生成占位立绘）、test_*.js（Node 测试）
serve.js              零依赖本地服务器
```

## 技术栈

纯浏览器原生 JS（无框架、无构建、无外部依赖）：Canvas 2D 渲染 + 自研脚本解析器 +
状态机播放器。经典 `<script>` 按序加载，`file://` 与任意静态服务器均可运行。

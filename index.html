    说明
    • 角色：一个角色 = 多个表情立绘 + 多句语音。脚本里用 chara://角色id/表情编号 引用立绘， 对话行加 {voice=语音编号} 播放该角色的语音。
    • 地点：一个地点 = 多张背景画面（如 早晨/中午/夜晚）。脚本里用 loc://地点id/画面id 引用。
    • 音乐/音效：脚本里用 @bgm bgm://音乐id（循环）、@sfx sfx://音效id（一次）； 或直接写文件路径（如 assets/audio/x.mp3）。
    • 「打包分享」把角色（含语音）/地点/音乐/音效导出为 JSON 包，别人用「导入」即可使用。
    • 数据保存在浏览器 localStorage（音频较占空间，超限会提示；打包文件不受此限制）。
